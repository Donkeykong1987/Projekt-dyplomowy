Nazwa aplikacji: System rejestracji pacjentów/klientów (np. psychoterapeuta, fizjoterapeuta)

Funkcje aplikacji
ETAP I:
Tworzenie bazy pacjentów/klientów (imię i nazwisko, email, nr telefonu, adres, data urodzenia, osoba do kontaktu z nr tel
Rozróżnienie via user
Możliwość przypisania/usunięcia daty i godziny wizyty dla danego pacjenta/klienta (rejestracja tylko o pełnych godzinach)
Widok kalendarza
Blokada terminu po jego wcześniejszym wyborze (brak doublebooking)
Zaznaczenie czy wizyta została opłacona czy nie
Możliwość wyeksportowania do pliku listy wizyt z randomowego okresu (tylko admin)
Dodanie załącznika do umówionej wizyty (tylko admin) – 

ETAP II:
Możliwość samodzielnego założenia konta przez pacjenta/klienta z danymi j.w (blokada na założenie konta na takie same dane)
Możliwość samodzielnego zapisania się na wizytę przez pacjenta/klienta
Opcja podglądu swoich wizyt
Możliwość zablokowania terminu przez Administratora jako niedostępne
Przypomnienie wysłane drogą mailową do pacjenta/klienta z informacja o zbliżającej się wizycie (np. 24h przed)

Użytkownicy:
Administrator
Pacjent/klient
